# Linux for beginners
A pointing informational website

You will need an empty USB stick, the Linux ISO of choice, and Balena Etcher to burn the ISO to the USB stick so it is bootable. Back up all your computer's hard drive data to an external hard drive before proceeding.

Coming from Microsoft Windows and looking for a stable desktop with support for NVIDIA drivers, a Windows 7 layout, gets out of you way so you can work, and customizable. May need an Ethernet cable to install Wi-Fi drivers. Terminal isn't required to use. Then try [Linux Mint Cinnamon](https://linuxmint.com/edition.php?id=326). Here is the [Linux Mint Cinnamon Installation Guide](https://linuxmint-installation-guide.readthedocs.io/en/latest/).
